# Student Performance Analysis

A data analysis project using Python and Jupyter Notebook to explore and visualise factors affecting student academic performance.

## What This Project Does

- Loads and cleans student performance dataset
- Performs exploratory data analysis (EDA)
- Visualises correlations between study habits, attendance, and grades
- Identifies key factors that influence student outcomes

## Tech Stack

- **Language:** Python
- **Libraries:** Pandas, Matplotlib, Seaborn, NumPy
- **Environment:** Jupyter Notebook

## How to Run

1. Clone the repository
```bash
   git clone https://github.com/shreya-User/student-performance-analysis.git
   cd student-performance-analysis
```
2. Install dependencies
```bash
   pip install pandas matplotlib seaborn numpy jupyter
```
3. Launch the notebook
```bash
   jupyter notebook Project-1-checkpoint.ipynb
```

## Key Insights

- Analysis covers factors such as study time, parental education, and attendance
- Visual charts included for grade distribution and correlation heatmaps
